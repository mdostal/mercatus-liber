# Naming Candidates

50 candidates for the project's real name, grouped by theme. None of these have been checked
against npm/domain/trademark availability — treat this as a shortlist to narrow from, then do
that check on whichever 3-5 survive a gut check. A few strong known collisions with existing
real projects/products were deliberately left off this list: **OpenCart** (existing PHP
commerce platform), **OpenBazaar** (a now-defunct decentralized commerce project, but still a
real prior-art name), **Commerce Layer** (an existing commerce API company), **StoreKit**
(Apple's in-app-purchase framework), and bare **Bazaar** (Bazaarvoice).

2. **Commerce Loom** — weaving independent adapters into one storefront.

4. **Meshcommerce**
5. **Modulcommerce** — modular commerce.

7. **Pluggable Commerce**

## How to actually narrow this
1. Gut-check: read the list out loud, cross off anything that doesn't sound sayable/typeable.
2. Check npm (`npm view <name>`) and the domain (`.dev`/`.io`/`.org`) for the survivors.
3. Quick trademark/collision sanity search for the top 3-5 before committing.
4. Rename is cheap right now (pre-alpha, no code, no external consumers) — don't over-invest in
   this decision before there's something real to name.
