Mercatus Liber

Mercatus Liber is real, free infrastructure — not a demo, not a funnel. It reads like the code it ships: direct, exact, and built to be taken apart.

// direct · precise · unembellished · confident

Scope: this is the framework's own identity — the landing page and docs site it will eventually apply to — not a replacement for or edit to packages/theming's 10 existing demo-store ThemeBundles (classic/dark/minimal/vibrant/retro/high-contrast/northline/editorial/maximalist/datasheet). Every color and font choice below was diffed against those 10 bundles' actual token values (read-only comparison — nothing in packages/theming was touched) specifically to avoid collision, not just checked against generic "AI design tell" advice. See brand-system.yaml's grounding block for the full findings.

Why these two, together

Public Sans was chosen over Inter/Space Grotesk specifically because those are the two "safe default" faces already named as generic-AI-design tells in this project's own artifact-design guidance — and over IBM Plex Sans / Archivo because datasheet and maximalist (two of the 10 demo bundles) already claim those. Public Sans is USWDS's own civic-infrastructure typeface, built for maximum neutral legibility rather than trend — a real fit for "free, MIT, no marketing veneer." JetBrains Mono is load-bearing, not decorative: it's a typeface literally designed for reading code day-to-day, which is exactly this framework's own stated differentiator (schema-first, adapter-swappable, AI-and-human-equal interfaces).

Logo Concepts

Disclosed substitution, not a fake or a skip: plugin-hive:logo-exploration's image-generation path requires the openai-image MCP tool. Checked live in this session — not assumed from the epic's earlier planning note — it reports CONNECTION_CLOSED, and separately this repo's own .mcp.json doesn't list an openai-image server entry at all, so logo-exploration is unavailable by both the live-connectivity check and the config-presence check the brand-system skill itself uses to decide its primary vs. fallback path. Per the epic's design discussion §2b, what follows is a real, well-reasoned typographic wordmark — not an icon mark, and not a placeholder. Wordmark-only identities are a legitimate, common choice for real open-source infrastructure projects. When openai-image reconnects, icon-mark exploration (see concept_directions in brand-system.yaml) is genuine, disclosed follow-on work — not something already claimed done here.

Primary lockup

Public Sans Bold carries the name — the system's one accent color, used once, at full weight. A JetBrains Mono tagline underneath, styled like a code comment, is the only mono in the lockup.

Compact / nav & footer chrome

All-lowercase, set entirely in the mono accent face — for contexts that are already mono-chrome (nav bar, footer, terminal-styled examples) where the primary lockup would be too heavy.

Package-identifier lockup

Styled like the real pnpm package scope this repo already ships (@mercatus-liber/core, @mercatus-liber/adapter-sqlite, …) — a wordmark treatment that's specific to how this project is actually built, not a generic lettermark.
