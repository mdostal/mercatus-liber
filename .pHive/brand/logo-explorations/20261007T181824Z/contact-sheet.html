Mercatus Liber — Logo Exploration, Round 2 (color + fresh directions)

After reviewing round 1 (.pHive/brand/logo-explorations/20261007T171307Z/, 12 candidates, all single-color Ledger Indigo on white), the human reviewer said: "not certain I like any of them... maybe we need to try with some colors so i can see something there." This round does two things in response: (A) recolors the single cleanest candidate from each of round 1's three directions into three new colorways apiece, so the existing concepts can actually be evaluated in color, and (B) explores three genuinely new concept directions, each rendered in four different colors so the color range itself is visible across the set. Per the operator's explicit instruction, this round goes wide on color — no constraint to the established Ledger Indigo palette.

Picking a winner (human decision)

This contact sheet and the 21 candidate PNGs are the review surface — selecting a final mark (from this round, round 1, or the inline-SVG fallback set in brand-guide.html) is deliberately left to a human, not decided by this generation pass. To record a selection, add selected.yaml to this same directory. For the recolor directions, use the original direction-<N> number (1, 2, or 3) since the mark geometry is unchanged from round 1 — note the colorway in notes. For the new directions, use 4, 5, or 6:

direction: 5      # integer; 1-3 = recolor of round-1 geometry, 4-6 = new concept
candidate: 2      # integer, matches <i>.png inside that direction (or recolor dir)
notes: |          # optional free text -- note the colorway chosen, e.g. "Deep Jade Teal"
  Rationale for the pick goes here.
